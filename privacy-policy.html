1. Overview & Product Scope

NEXORA X (com.nexora.x) is a free, user-configured Android VPN and proxy client utility powered by the open-source sing-box (libbox v1.10.7) engine.

  • Bring-Your-Own-Configuration Utility: NEXORA X does not provide, sell, rent, or operate public or commercial VPN servers. Users import and manage their own server configurations (VLESS, VMess, Trojan, and Shadowsocks).
  • No Accounts, Subscriptions, or Ads: NEXORA X requires no user registration, no login, no in-app purchases, and contains zero third-party advertising or analytics SDKs.
  • No Developer Backend: NEXORA X does not communicate with any backend server, telemetry collector, or remote database operated by [PUBLISHER_NAME].

2. How NEXORA X Uses Android VpnService

NEXORA X uses the Android system android.net.VpnService API strictly to provide user-initiated VPN tunneling:

  1. Prominent In-App Disclosure & Explicit Consent: Before invoking Android's system VPN permission dialog (VpnService.prepare()), NEXORA X displays an in-app prominent disclosure explaining how VpnService operates and requires your explicit consent.
  2. Local Virtual Network Interface (TUN): When you explicitly tap Connect, NexoraVpnService opens a local virtual network interface (172.19.0.1/30, gVisor user-space stack) on your device.
  3. Encrypted Tunneling to Your Configured Server: Network traffic captured by the local TUN interface is encrypted in memory by sing-box (using the TLS, Reality, XTLS, or AEAD cipher settings in your selected profile) and routed directly to the remote server address and port that you configured.
  4. User Control & Persistent Foreground Notification: While connected, a persistent Android foreground notification displays the active profile name, connection state, and a one-tap Stop VPN button so you can disconnect at any time.

4. Network Connections Initiated by the Application

  • Your Configured VPN / Proxy Server: When you connect or run a TCP latency check, your device connects directly to the hostname/IP and port in your selected profile. Because you supply that server, its privacy practices are governed by your chosen server operator.
  • Tunnel DNS & Connectivity Verification: During an active session, sing-box uses 1.1.1.1 to bootstrap outbound domain resolution and https://1.1.1.1/dns-query (DNS-over-HTTPS through your tunnel) for remote DNS resolution. To verify that internet traffic actually flows through the tunnel (Stage F), the app sends a standard HTTP 204 No Content probe to http://cp.cloudflare.com/generate_204 without transmitting any personal or device-identifying information.
